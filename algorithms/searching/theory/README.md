# Searching Algorithms Theory

Searching algorithms are designed to retrieve information stored within some data structure or define a search space where a target is located.

## Common Searching Algorithms

- **Linear Search**: Checks every element in the list sequentially until the target is found.
  - Time Complexity: $O(N)$
  - Space Complexity: $O(1)$
- **Binary Search**: Finds the position of a target value within a sorted array by repeatedly dividing the search interval in half.
  - Time Complexity: $O(\log N)$
  - Space Complexity: $O(1)$
