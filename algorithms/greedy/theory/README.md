# Greedy Algorithms Theory

A greedy algorithm is an algorithmic paradigm that follows the problem-solving heuristic of making the locally optimal choice at each stage with the hope of finding a global optimum.

## Properties of Greedy Problems
1. **Greedy Choice Property**: A global optimal solution can be arrived at by making locally optimal (greedy) choices.
2. **Optimal Substructure**: An optimal solution to the problem contains within it optimal solutions to subproblems.

## Classic Examples
- Fractional Knapsack
- Huffman Coding
- Dijkstra's Shortest Path (also a graph algorithm)
- Kruskal's / Prim's Minimum Spanning Tree
